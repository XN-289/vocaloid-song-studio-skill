# AI 音乐创作自评自检规范 v6.0（封档）

> 用户实测蒸馏的评分器作战手册，单文件自包含。2026-10-15 存档于本项目。
> 通用版 · 九定律五强规律三假设 · 全部样本与来源信息已融解

## 核心

- ★ 核心一：歌词和氛围是进场的必要条件；至少一个维度立峰，才是分数的充分条件——全项中规中矩无峰即沉底。
- ★ 核心二：单首分数是彩票，配置水位是实力；配方的价值，是把运气变成工资。
- ★ 核心三：7.9+ 的胜负手不在词，在「人声演绎是否服从人设」——概念 × 演绎 × 金句 × 弧线。

## 九定律

| 定律 | 内容 | 行动含义 |
| --- | --- | --- |
| L1 引用定律 | 被引句 100% = 强动词 + 可被作用的（半）具体对象；抽象情感词必须挂具体动词。跨语言成立。对仗句的最小引用单位是『对』。锚点句跨版本不动。反向规则：搬运名句/公共库存会被打『略熟』标签 | 押「动词带画面」句；锚点句形成后不再动；用典做细节不做骨架；写自家观察 |
| L2 评分确定性 | 同一作品重复评估，分数与评语逐字一致；跨周重评分数纹丝不动，名次随总池重排 | 同音频重投无意义；分数波动全部来自生成端 |
| L3 同ID不重评 | 同一作品 ID 改标题/改歌词不触发重新评估 | 迭代必须生成新音频 |
| L4 水位法则 | 同配置分差约 ±0.15，n=4 时均值趋于稳定；每日评分额度归属作品创作者，重复分享扣次 | 水位=两首均值（n≥3 更稳）；读他人评语=消耗对方额度，须同意或限量 |
| L5 弱点槽 | 每条评语至少分配一个弱点，全分段（含榜首）措辞几乎不变；高分作品可一次领两条；槽位随修补漂移。其所谓「钩子」特指旋律动机层面——词记忆与调记忆分离 | 措辞不构成工单；词好记≠歌好记；让槽位落在旋律层 |
| L6 净化层 | 歌词中特定字被静默同音替换（月份词、生僻字实测命中）；标题栏免疫 | 核对歌词面板；同音异形字保发音或统一安全词 |
| L7 旋律不可控 | 旋律层作曲与提示词改动多次实验，分值变化均在噪声带内；评分器明索的旋律点提示词够不着 | 旋律层永不投预算；词/结构/人声层吃满 |
| L8 Hook 配方与重复颗粒度 | 配方=框架三选一+呼语门框+首尾回扣。框架：①排比疑问 ②数字递进 ③口语短句反复——三型均获评分器明牌认证；框架词必须是日常话语碎片且具体。门框=前短呼×2+后长呼落点+固定两音动机，可前置到预副歌结尾先立。颗粒度：重复单位限句级（单句/句对），段级原样复现=扣分；预副歌第二次必须一词翻转 | 钉句子不填段落；框架选对、门框钉牢、翻转防薄 |
| L9 文本校对 | 评分器逐字校对歌词：错别字/malformed 字被明文点名「打断沉浸」。平台矛盾：TTS 唱不出的字迫使同音字替身→显示文本污染→评分器扣分。处置：换词（首选）＞正字（次选）＞同音字替身（仅艺术线） | 冲榜作品显示文本必须零污染；逐字校对合并进歌词面板核对动作 |

## 五强规律

| 强规律 | 内容 |
| --- | --- |
| S1 评分器无身份权重 | 平台所有者作品分数与评语结构与其他作者无差异。高分稀缺是真实稀缺 |
| S2 格式兼容 | 歌词栏中文短标注安全；长英文指令标签曾致评分流水线无法读取歌词。歌词栏中文短标注；英文放风格栏 |
| S3 分数段指纹 | 「相对亮点/相对加分项」=6.5 档指纹；全项及格+「中规中矩」=无峰后 10% 档。带方位词（主歌/副歌）与度量词（偏密/更短）的批评是真实反馈，空泛款是槽位填充 |
| S4 人声演绎杠杆 | 高分区共同抬分项：演绎服从人设（戏谑配戏谑、双人配对话、成熟配回望）。评分器在 7.6+ 档主动索取「隐忍到爆发」的层次弧线。音色好听≠高分。声乐指令写「她是谁、怎么唱」，不写「她多好听」 |
| S5 金句经济学 | 顶级金句是可移植资产：同一句杀器跨作品复用。配套：点题呼应句（呼应标题的问/答把歌名焊进歌词）；宏大题材金句沉到身体痛感；主歌物象铺垫后副歌一句直给是刀，通篇直给是病 |

## 三假设

| 假设 | 内容 |
| --- | --- |
| H1 可移动天花板 | 顶部 7.9+ 为配方区；单一创作者多作品同区间可稳定存在。无鼓慢歌常见水位带 7.0-7.2 → 慢歌末段加鼓事件 |
| H2 跨平台审美差 | 不同评分平台审美存在系统性差异，分差未校准。跨平台分数禁止直接互比 |
| H3 规范栈独立分值 | 同故事对照：规范栈位移 +0.35（强倾向）。规范栈可复制可教学 |

## 金句库（六支+用法指南）

①物象动作 ②否定转折 ③取舍转折 ④生活化比喻 ⑤反差对照（命中率最高支）⑥悖论矛盾。
用法：冲顶配两支不同支；点题呼应句焊歌名（「心安才是归处」式）；宏大题材沉身体（家国→痛感，思念→物件）；候选第七支：时间反转（小时候我护你/今天我换岗），待复现转正。

## 100 分自评表（权重）

| 维度 | 权重 | 优秀 | 良好 | 合格 | 待改 |
| --- | --- | --- | --- | --- | --- |
| 歌词与主题表达 | 25 | 23-25 | 19-22 | 15-18 | <15 |
| 情绪与氛围统一 | 15 | 14-15 | 12-13 | 10-11 | <10 |
| 旋律与 Hook | 20 | 18-20 | 15-17 | 12-14 | <12 |
| 结构与动态 | 15 | 14-15 | 12-13 | 10-11 | <10 |
| 编曲与伴奏 | 10 | 9-10 | 8 | 6-7 | <6 |
| 人声表现 | 8 | 8 | 7 | 5-6 | <5 |
| 创新与辨识度 | 7 | 7 | 6 | 4-5 | <4 |

自评必须附证据（引原文/时间码），写不出证据的自评自动降一档。检查「我的峰」：至少一个维度优秀，否则按无峰处理。

## 快速自检 10 问（依赖式）

1. （根）一句话情绪是什么？
2. （根）一句话概念/人设是什么？
3. （峰）你的峰在哪个维度？
4. （Hook）框架三选一+门框+颗粒度（句级重复）？
5. （金句）六支哪两支？有焊歌名的点题呼应句吗？
6. （歌词）意象≤3 有主次吗？
7. （演绎）人声演绎方式写明了吗？（她是谁/怎么唱/动态弧线）
8. （结构）预副歌第二次一词翻转了吗？Bridge 后有变化吗？
9. （执行）慢歌末段有物理峰值事件吗？结尾有余味吗？
10. （文本）歌词面板逐字校对了吗？

## 专项排雷

- 敏感字静默替换（L6）：核对面板；同音异形字或统一安全词
- 同 ID 不重评（L3）：迭代必须新音频
- 每日额度归属创作者（L4）：读他人评语须同意/限量
- 长英文标签崩解析（S2）：歌词栏中文短标注
- 回退态两分：无引用+全通用建议=兜底不计数；明确提示无歌词=正常空评
- 维护窗口：迟迟不出分/兜底=维护信号，停投
- 单样本高分幻觉（L4）：历史单首高分不作配置水位
- 弱点槽措辞（L5）：含榜首全分段措辞不变；补哪漂哪；方位词+度量词=真实反馈
- 分数段指纹（S3）：「相对亮点」=6.5 档；「中规中矩」=无峰后 10% 档
- 段级重复（L8）：整段原样复现=扣分；改单句对回扣+一词翻转
- 错字/同音字替身（L9）：冲榜显示文本零污染；TTS 坑词优先换词
- 公共库存名句（L1）：搬运名句=「略熟」；写自家观察
- 旋律批评恒定（L7）：默认归宿不作依据；词好记≠歌好记

## 对照自检表（平庸形态→升级动作）

| 平庸形态 | 升级动作 |
| --- | --- |
| 无峰：全项还行 | 选定一个维度做到优秀 |
| 概念一句话讲不妙 | 把两个不搭的东西焊在一起试试 |
| 副歌整段重复 | 单句对首尾回扣（钉句子不填段落） |
| 预副歌原样再来一遍 | 一词翻转 |
| 框架词生造/通用 | 换日常话语碎片且具体 |
| 金句抽象抒情 | 六支句式选换；点题呼应焊歌名；宏大沉身体 |
| 意象超 3 个 | 砍到 ≤3，留主攻方向 |
| 密句无呼吸 | 密句后加疏句；直给后留留白 |
| 人声唱得好但不对 | 写人设演绎方式（S4） |
| 编曲全程铺底 | 乐器出场时刻表 |
| 结尾收在歌声里 | 声音设计收尾留空 |
| 显示文本有错字/替身 | 逐字校对；TTS 坑词换词优先 |
| 标题与歌词两个名字 | 净化层命中时统一安全词 |

⚠ 评分器永远给出至少一条弱点（L5）。自检的目标不是零弱点，而是让槽位落在旋律层，可控维度全部堆满，至少一个维度立峰。

## 改进优先级

固定基准序：概念/人设 ＞ 歌词金句 ＞ Hook 配方 ＞ 人声演绎（S4）＞ 结构动态 ＞ 情绪统一 ＞ 编曲 ＞ 创新点。
联动规则：失分最多维度优先；差 ≤3 时按基准序。
高位策略：≥7.4 后新杠杆去新作品验证；7.7+ 优先补人声演绎与概念；旋律层永不追；金句考虑系列化（S5）。

## 提交前终检清单

1. 歌名/创作者完整（口语碎片优先；双主角可用框架词对）
2. 一句话概念讲得妙
3. 立峰维度已选定并达到优秀
4. 歌词 ≥2 金句（六支）+点题呼应句+意象≤3
5. 显示文本逐字校对零污染（错字/替身/公共库存）
6. Hook = 框架+门框+首尾回扣，重复单位句级
7. 人声人设化演绎定义已写明
8. 预副歌第二次一词翻转
9. 版权①②③④ 已确认
10. 自评分已填（每项附证据）
11. 歌词栏中文短标注，无长英文指令
12. 歌词面板已核对（净化层+错字一次过）
13. 本次为新生成音频（新 ID）

★ ★ 冲榜必选项：附结构标注（乐器出场时刻表 / Bridge 留白 / 末段动态事件）——实测带标注作品的结构分被稳定保护，且标注内容会被评语逐件复述。

## 水位分段行动（实测校准）

| 水位 | 位置 | 行动 |
| --- | --- | --- |
| 7.9+ | 顶部配方区 | 概念×演绎×金句×弧线四件齐活；打磨人声演绎（S4）；金句系列化（S5） |
| 7.6-7.8 | 高位 | 补人声动态弧线与概念一句话；只微调 |
| 7.4-7.5 | 高位稳态 | 配方满配；选定立峰维度 |
| 7.0-7.3 | 中区（无鼓慢歌常见带） | 净化层；末段鼓事件；金句密度 |
| 6.5-6.9 | 中下游（指纹区） | 结构+Hook 双改；规范栈全上（H3） |
| <6.5 | 底部（无峰高危区） | 先立峰再谈其余；词好人不差的优先补架构（最常见缺口） |

## 版本迭代策略（测量学）

- 水位=同批两首均值（L4）；单首是彩票；n≥3 更稳。
- 两首都评取均值；同批不做单变量对照。
- 迭代必须新音频（L2/L3）。
- 额度管理：每日限额归属作品创作者；读他人评语须同意（L4）。
- 证据卫生：样本标注接触状态——独立/采用者/设计者；定律引用锚定独立组。
- 一次只改一类变量；改动前预设判定线。
- 同类改动最多试一次；无效不重复（旋律层），有效不榨干（词/结构层）。
- 历史单首高分不得作为配置水位。
- 验证成功的杠杆写入配方去新作品复现；天花板随配方刷新（H1）。
- 兜底评语/维护信号时停投保额度。
