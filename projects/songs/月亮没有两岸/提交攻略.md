## 二、赛制与打法（专题页已核实）

1. **人工审核**：提交后先过人工审核。
2. **72 小时热度窗口**：审核通过后进入 72 小时互动热度期，按播放、推荐、评论、分享计算热度；单曲组热度前 50 名、专辑组前 20 名进入复评。
3. **综合复评**（10 月 30 日开始）：100 位大众评审占 50%，10 位专业评审占 30%，AI 评审占 20%。
4. **打法结论**：
   - 真正的门槛是 72 小时热度窗口——提交时机要选在你方便动员的时段（晚上提交，白天+晚上两轮动员最划算）。
   - 本曲的家庭亲情叙事对长辈群体传播友好，动员面比校园小情歌更宽：同学群、亲友群、家族群、朋友圈都能发。
   - 热度靠真实互动，不要刷量（人工审核+AI 评审都在看，异常数据反而扣分）。
   - 大众评审占 50%——温暖、好懂、有记忆点就是为这 50% 设计的。

## 四、叙曲 App 生成要点

1. **粘贴歌词**：直接粘贴 `lyrics-zh.md` 中 ```text 代码块内的全部内容（含结构标记）。
2. **风格字段（详细版必用）**：接口只支持「歌词+风格」两个字段时，风格粘贴 `music-agent-prompt.md` 第十二节的**中文详细版**（含 BPM、调性、编曲、段落动态、人声要求与注音说明）；接口只认英文时用同节的英文详细版；限字数时才用超短版。
3. **一次只改一个变量**：首版不满意时，按顺序单改——先换人声情绪（更暖/更厚），再调民乐浓度，最后才考虑换风格描述。
4. **首选温暖女声**：平台无女声选项时用男声版（整体偏柔，歌词无需改动）。
5. **多生成几版再选**：同参数至少生成 2–4 版，按 `music-agent-prompt.md` 第十三节验收表逐项听，选最接近的一版提交。

## 五、试听验收要点（人耳版）

1. 副歌第一句「月亮没有两岸」是否上口、能否跟唱。
2. 「有」「两」是否短促，长音是否落在「亮」上（听感不别扭）。
3. Verse 2 的歌仔戏清唱句是否像从远处传来、只出现一次、不抢主唱。
4. Bridge 是否突然安静、干声贴身（与副歌大混响形成对比）。
5. Outro「台湾，饭还热着」是否最轻最实，最后一句是否近乎清唱。
6. 中文咬字清楚，无英文腔、无乱码、无唱出的段落标签。

## 六、迭代路径（哪不对改哪）

| 症状 | 处理 |
| --- | --- |
| 整体不对 | 换平台风格描述为长自然语言版，重生成 |
| 人声不对（太老/太油/太尖） | 风格字段改人声描述：`温暖年轻女声，民谣底子，真诚` |
| 律动不对（太快/太赶） | 确认 BPM 88；风格字段加 `gentle, warm` |
| hook 不行（记不住） | 保持歌词不动，重生成选版；仍不行再考虑副歌旋律重掷 |
| 歌仔戏句出戏 | 降低该句突出度重新生成，或局部重掷 Verse 2 |
| 结尾弱（Outro 没收住） | 平台支持尾段裁剪/重生成优先；或整曲多生成几版对比 |
| 咬字不清 | 按 `lyrics-singing-guide.md` 固定读音说明重新生成，不改词 |

## 七、双曲策略（投稿数量不限）

- 《未来已开机》（未来想象主题）与《月亮没有两岸》（亲情友情主题）可同时投稿，题材互不冲突。
- 若只投一首，建议先投这首——情感浓度与记忆点（碗筷、饭还热着）更硬。
- 两首都定稿后，可再打磨一首「校园×城市记忆」（临港灯塔线）形成三线布局。
