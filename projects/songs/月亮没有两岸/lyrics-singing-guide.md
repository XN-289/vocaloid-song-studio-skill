# 《月亮没有两岸》唱读固定与发音指南

> 派生自 `lyrics-zh.md` v1.3-frozen，逐字一致，禁止版本漂移。
> 歌词中已带全角括号注音（阿嫲（a ma）等），生成时请勿唱出括号内容；本文件为完整发音约束。

## 一、固定读音（多音字、方言词与易错字）

| 词 | 固定读音 | 说明 |
| --- | --- | --- |
| 阿嫲 | ā mǎ | 闽南语 a-má 的普通话唱法，两个字都唱实；歌词中已注音（a ma） |
| 歌仔戏 | gē zǐ xì | 「仔」读 zǐ |
| 念白 | niàn bái | 戏曲术语，不是「念白（bó）」 |
| 银发 | yín fà | 「发」读 fà（头发），不读 fā；歌词中已注音（fa） |
| 模样 | mú yàng | 「模」读 mú |
| 擦 | cā | 阴平，唱实 |
| 开席 | kāi xí | 「席」阳平 xí |
| 姑婆 | gū pó | 祖母的姐妹（闽南习俗称呼） |
| 的 / 了 / 着 | de / le / zhe | 轻读，绝不落长音 |
| 一 | yì / yí | 按后字声调变读（一眼 yì、一段 yí、一家 yì） |
| 不 | bù / bú | 后接去声读 bú（不算、不用），其余读 bù |

## 二、Hook 声调位（高危位置约束）

核心 hook「月亮没有两岸」全曲出现 7 次（Chorus 1/2/Final 各 2 次 + Outro 1 次），逐字同槽：

```
月(yuè) 亮(liàng) 没(méi) 有(yǒu) 两(liǎng) 岸(àn)
   4       4        2       3        3       4
```

- 长音落「亮」（去声，自然下落），「岸」收束短而稳。
- 「有」「两」（上声）必须短，短上滑音带过，禁止拖长（拖长会听成「由/凉」）。
- Outro 的 hook 轻声唱出，像自言自语。

## 三、逐行高危检查（行尾字与声调）

- 全词行尾无「的/了/着」；「擦」「家」「响」「达」等阴平/阳平行尾可持续。
- 「回家的路从来不遥远」：尾字「远」（上声）必须短收、落在句尾低音释放位，禁止长音高唱（长音高唱会倒成「圆」）。
- 「说月亮会替她先看一眼」：尾字「眼」（上声）同上处理，短收。
- 「等你回家把团圆饭吃完」：尾字「完」（阳平）可持续。
- 「台湾，饭还热着」：「台湾」两字唱实唱稳，是全曲唯一的主题词出现位；「热着」的「着」轻收。

## 四、换气与停顿点

- 一行 = 一口气 = 一个乐句；逗号是短停指令。
- Intro 轻唱，句间留白一拍以上。
- Bridge 第 5 行「等你回家，我们开席」：逗号处换半口气，「开席」前留半拍白，后接 Final Chorus 强进。
- Chorus 每两行一呼吸：hook 行唱完立即接内容行，第 2、4 行后换气。

## 五、轻唱、戏曲句与声线区分

- Intro 两行：主唱轻声唱出（转述阿嫲的话），近距离。
- Verse 2 第 5 行「她发来一段歌仔戏清唱」之后的戏曲乐句：独立远声线（男女皆可），戏曲风味、朦胧、带轻混响，像从海那边传来；只出现这一次。
- Outro 第 2 行「台湾，饭还热着」：主唱轻声逐字，唱得最轻最实。
- 其余全部由主唱正常演唱；全曲没有任何念白，每一句都唱出来。

## 六、段落标签与制作说明

- 全部结构标记（[主歌一] 等中文短标注）只作段落指令，不得唱出。
- 不得增加未标注的衬词、喊声、说唱或即兴；Final Chorus 的群体合唱只重复唱词本身。
