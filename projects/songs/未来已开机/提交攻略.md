## 三、叙曲 App 生成要点

1. **粘贴歌词**：直接粘贴 `lyrics-zh.md` 中 ```text 代码块内的全部内容（含结构标记）。
2. **风格字段（详细版必用）**：接口只支持「歌词+风格」两个字段时，风格粘贴 `music-agent-prompt.md` 第十二节的**中文详细版**（含 BPM、调性、编曲、段落动态、人声要求与注音说明）；接口只认英文时用同节的英文详细版；限字数时才用超短版。
3. **一次只改一个变量**：首版不满意时，按顺序单改——先换人声情绪（更亮/更内省），再调风格权重，最后才考虑换风格描述。不要每次全部重填。
4. **首选女声**：平台无女声选项时，用男声版（整体听感偏清亮，歌词无需改动）。
5. **多生成几版再选**：同参数至少生成 2–4 版，按 `music-agent-prompt.md` 第十三节验收表逐项听，选最接近的一版提交。

## 四、试听验收要点（人耳版）

1. 副歌第一句「未来已开机」是否上口、能否跟唱（hook 合格的最低标准）。
2. 「已」是否短促，长音是否落在「开」上（听感不别扭）。
3. Chorus 2 与 Chorus 1 是否逐字一致；Final Chorus 第 3 行是否唱的「未来我开机」。
4. Bridge 是否突然安静、干声贴身（与副歌大混响形成对比）。
5. Outro「收到，信号满格」是否由和声/第二声线回答。
6. 中文咬字清楚，无英文腔、无乱码、无唱出的段落标签。

## 五、迭代路径（哪不对改哪）

| 症状 | 处理 |
| --- | --- |
| 整体不对 | 换平台风格描述为长自然语言版，重生成 |
| 人声不对（太老/太油/太幼） | 风格字段改人声描述：`年轻女声，清亮真诚，少年气` |
| 律动不对（太慢/太软） | 确认 BPM 136；风格字段加 `driving drums, energetic` |
| hook 不行（记不住） | 保持歌词不动，重生成选版；仍不行再考虑副歌旋律重掷 |
| 某段弱（通常是 Bridge） | 平台支持局部重生成就用 Bridge 重掷；否则整曲重掷选版 |
| 结尾弱（Outro 没收住） | 平台支持尾段裁剪/重生成优先；或整曲多生成几版对比 |
| 咬字不清 | 按 `lyrics-singing-guide.md` 的固定读音说明重新生成，不改词 |
