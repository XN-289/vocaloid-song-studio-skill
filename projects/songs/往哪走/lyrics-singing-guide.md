# 《往哪走》唱读固定与发音指南

> 派生自 `lyrics-zh.md` v1.2-frozen，逐字一致，禁止版本漂移。
> 歌词中已带全角括号注音（模（mu）等），生成时请勿唱出括号内容；本文件为完整发音约束。

## 一、固定读音（多音字与易错字）

| 词 | 固定读音 | 说明 |
| --- | --- | --- |
| 有模（mu）有样 | yǒu mú yǒu yàng | 「模」读 mú，不读 mó；歌词中已注音（mu） |
| 调（tiao）响 | tiáo xiǎng | 「调」读 tiáo（调节），不读 diào；歌词中已注音（tiao） |
| 才算数 | cái suàn shù | 「数」读 shù |
| 张望 | zhāng wàng | 「张」唱实 |
| 的 / 了 / 地 | de / le / de | 轻读，绝不落长音 |

## 二、Hook 声调位（高危位置约束）

核心 hook「往哪走，都在往前走」全曲出现 8 次（前奏 1 + 三个 Chorus 各 2 + 尾声 1），逐字同槽：

```
往(wǎng) 哪(nǎ) 走(zǒu)，都(dōu) 在(zài) 往(wǎng) 前(qián) 走(zǒu)
   3       3     3        1      4      3       2      3
```

- 「往哪走」三个上声连读，唱得短促、像真的在问；「走」短收有力，不拖长。
- 长音落「前」（阳平，可持续），第二个「走」干脆收束。
- 副歌其余行尾「口/由/愁/头」：口短收，由/愁/头可持续。

## 三、逐行高危检查（行尾字与声调）

- 全词行尾无「的/了/着」。
- 「只有我的船还停在港」：尾字「港」（上声）短收，落句尾低音释放位。
- 「先起床，再想方向」：尾字「向」去声自然下落。
- 「往前走，就是全部」：尾字「部」去声自然下落。

## 四、换气与停顿点

- 一行 = 一口气 = 一个乐句；逗号是短停指令。
- Chorus 每两行一呼吸：hook 行唱完立即接内容行，第 2、4 行后换气。
- 桥段 第 5 行「往前走，就是全部」前留半拍白，后接 结尾副歌 强进。

## 五、轻唱与声线区分

- 前奏 与 Outro：主唱轻声唱出，像自言自语，不是念白。
- 副歌：主唱（女声）+ 男声低音和声层 + 群体大合唱；结尾副歌 男女声混合大合唱。
- 主歌：主唱贴耳内省，像深夜对自己说话。
- 全曲没有任何念白，每一句都唱出来。

## 六、段落标签与制作说明

- 全部结构标记（[主歌一] 等）只作段落指令，不得唱出。
- 不得增加未标注的衬词、喊声、说唱或即兴。
- 副歌一、2 整段逐字一致；结尾副歌 仅末行升级（点头→跟你挥手）。
