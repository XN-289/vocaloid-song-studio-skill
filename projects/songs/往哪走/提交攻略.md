- 短视频截点：Intro+Chorus 1 前 15 秒可独立成片。

## 四、叙曲 App 生成要点

1. **粘贴歌词**：直接粘贴 `lyrics-zh.md` 中 ```text 代码块内的全部内容（含结构标记）。
2. **风格字段**：粘贴 `style-详细版.md` 的中文详细版；接口只认英文时用英文详细版；限字数才用超短版。
3. **一次只改一个变量**：首版不满意时，按顺序单改——先换合唱浓度，再调 Bridge 干湿度，最后才考虑换风格描述。
4. **首选女声**：平台无女声选项时用男声版（歌词无需改动）。
5. **多生成几版再选**：同参数至少生成 2–4 版，按 `music-agent-prompt.md` 第十三节验收表逐项听。

## 五、试听验收要点（人耳版）

1. 前 3 秒能不能跟着哼「往哪走，都在往前走」。
2. hook 第一遍有没有「真的在问」的感觉。
3. 「往哪走」三个上声连读是否自然不拗口。
4. Bridge 是否突然只剩钢琴和人声。
5. Final Chorus 升调那一刻顶没顶上去。
6. 尾声「先起床，再想方向」是否越来越轻。
7. 中文咬字清楚，无英文腔、无唱出的段落标签、无念白。

## 六、迭代路径（哪不对改哪）

| 症状 | 处理 |
| --- | --- |
| 副歌问句感不足 | 风格字段加「hook 第一遍稍慢」，重生成 |
| 太丧 | 风格字段加强「副歌合唱与鼓组」，Verse 保持安静 |
| 太像说教 | 风格字段降低「预副歌弦乐强度」，重生成 |
| 人声不对 | 风格字段改人声描述：`温暖年轻女声，贴耳内省` |
| hook 记不住 | 保持歌词不动，重生成选版 |
| 结尾没收住 | 平台支持尾段裁剪/重生成优先；或整曲多生成几版对比 |
| 咬字不清 | 按 `lyrics-singing-guide.md` 固定读音说明重新生成，不改词 |
