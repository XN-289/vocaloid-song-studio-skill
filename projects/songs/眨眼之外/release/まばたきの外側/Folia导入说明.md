# Folia 导入说明

这个目录是最小化的一键文件夹导入包。

```text
まばたきの外側/
├─ まばたきの外側.wav       主音频
├─ まばたきの外側.lrc       主时间轴歌词
├─ まばたきの外側.t.lrc     中文翻译歌词
├─ cover.png              文件夹封面
└─ .foliaignore          可选备份忽略规则
```

在 Folia 的“本地音乐”区域点击“导入文件夹”，选择当前目录。音频与歌词使用相同基础名，封面使用 Folia 优先识别的固定文件名。

若这个目录以前导入过，请执行“重新导入”。Web 版文件夹导入依赖 File System Access API；不可用时使用桌面版或支持该 API 的 Chromium 系浏览器。
