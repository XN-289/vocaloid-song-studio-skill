# Folia 导入说明

这个目录已整理为可直接导入的歌曲文件夹。

```text
《恋色デュエル》/
├─ 恋色デュエル.wav       主音频
├─ 恋色デュエル.lrc       日文时间轴歌词
├─ 恋色デュエル.t.lrc     中文翻译歌词
├─ cover.png              文件夹封面
└─ .foliaignore           源素材忽略规则
```

在 Folia 的“本地音乐”区域点击“导入文件夹”，选择当前 `《恋色デュエル》` 目录。音频与歌词使用相同基础名，封面使用 Folia 优先识别的固定文件名。

目录中的 MP3、Tunee 原始 LRC 和原始封面文件已通过 `.foliaignore` 排除，作为备份保留。若以前导入过此目录，请执行“重新导入”。Web 版文件夹导入依赖 File System Access API；不可用时使用桌面版或支持该 API 的 Chromium 系浏览器。
