## 二、本曲的赛制针对性

- 前 3 秒 hook 落地：热度窗口里第一秒抓不住人就划走了。
- 拍手跟唱：副歌全体拍手，评论区可以发起「拍手接龙」，天然制造互动。
- 直白歌词：大众评审 50 分里不需要文学解读，听懂就是喜欢。
- 短视频截点：Intro+Chorus 1 前 15 秒可独立成片，直接发朋友圈/视频号。
- 动员话术：「听完你会想@一个朋友」——亲情友情向的传播钩子。

## 四、叙曲 App 生成要点

1. **粘贴歌词**：直接粘贴 `lyrics-zh.md` 中 ```text 代码块内的全部内容（含结构标记）。
2. **风格字段**：粘贴 `style-详细版.md` 的中文详细版；接口只认英文时用英文详细版；限字数才用超短版。
3. **一次只改一个变量**：首版不满意时，按顺序单改——先换合唱浓度，再调拍手强度，最后才考虑换风格描述。
4. **首选女声**：平台无女声选项时用男声版（歌词无需改动）。
5. **多生成几版再选**：同参数至少生成 2–4 版，按 `music-agent-prompt.md` 第十三节验收表逐项听。

## 五、试听验收要点（人耳版）

1. 前 3 秒能不能跟着哼「别怕别怕，我在呢」。
2. 副歌的拍手节奏是否想让人跟着拍。
3. 「别怕」四字是否短促有力，「呢」是否短收带暖意。
4. Bridge 是否突然只剩钢琴和人声，「一二三」是否像数数。
5. Final Chorus 升调那一刻顶没顶上去。
6. 尾声「我在呢」是否越来越轻、近乎气声。
7. 中文咬字清楚，无英文腔、无唱出的段落标签、无念白。

## 六、迭代路径（哪不对改哪）

| 症状 | 处理 |
| --- | --- |
| 副歌喊不起来 | 风格字段加强「大合唱」「拍手」，重生成 |
| 太像喊口号 | 重生成选版；仍不行就降 Bridge 前鼓组强度描述 |
| 拍手太吵 | 风格字段加「拍手只出现在副歌」，重生成 |
| 人声不对 | 风格字段改人声描述：`明亮温暖年轻女声，直白口语感` |
| hook 记不住 | 保持歌词不动，重生成选版 |
| 结尾没收住 | 平台支持尾段裁剪/重生成优先；或整曲多生成几版对比 |
| 咬字不清 | 按 `lyrics-singing-guide.md` 固定读音说明重新生成，不改词 |
