## 一、固定读音（多音字与易错字）

| 词 | 固定读音 | 说明 |

| 数（shu）心跳 | shǔ xīn tiào | 「数」读 shǔ（数数），不读 shù；歌词中已注音（shu） |
| 冲（chong）我笑笑 | chòng wǒ xiào xiào | 「冲」读 chòng（朝着），不读 chōng；歌词中已注音（chong） |
| 咽（yan）回肚里 | yàn huí dù lǐ | 「咽」读 yàn（吞咽），不读 yān/yè；歌词中已注音（yan） |

| 考砸了 | kǎo zá le | 「砸」读 zá |
| 跌跌撞撞 | diē diē zhuàng zhuàng | 四字都唱实 |
| 歇歇脚 | xiē xiē jiǎo | 「歇」读 xiē |
| 的 / 了 / 地 / 着 | de / le / de / zhe | 轻读，绝不落长音 |
| 一 | yì / yí | 按后字声调变读（一起 yì、一二三 yī） |

## 二、Hook 声调位（高危位置约束）

核心 hook「别怕别怕，我在呢」全曲出现 8 次（前奏 1 + 三个 Chorus 各 2 + 尾声 2），逐字同槽：

```
别(bié) 怕(pà) 别(bié) 怕(pà)，我(wǒ) 在(zài) 呢(ne)
   2      4     2      4       3      4     轻
```

- 「别怕」四字短促有力，适合全场齐喊；每个「怕」收得干脆。
- 长音落「在」（去声，自然下落），「呢」短收带暖意，禁止拖长。
- 「我」（上声）短上滑音带过，不与「在」抢长音。

## 三、逐行高危检查（行尾字与声调）

- 全词行尾无「的/了/着」。
- 「天塌下来我不躲开」「明天太阳会出来」：尾字「开」「来」阴平/阳平，可持续。
- 「拍拍手，别发呆」「把歌大声唱出来」：尾字「呆」「来」阳平，可持续。
- 「一二三，谁都不许哭鼻子」：尾字「子」轻短收，唱出俏皮感。

## 四、换气与停顿点

- 一行 = 一口气 = 一个乐句；逗号是短停指令。
- Chorus 每两行一呼吸：hook 行唱完立即接内容行，第 2、4 行后换气。
- 桥段 第 4 行「一二三」三个字各占一拍，像数数，唱完直接冲进 结尾副歌。

## 五、轻唱与声线区分

- 前奏 与 尾声 的 hook：主唱轻声唱出，像哄人、像自言自语，不是念白。
- 副歌：主唱（女声）+ 男声低音和声层 + 群体大合唱；结尾副歌 男女声混合大合唱。
- 主歌：主唱贴耳直白，像对朋友说话。
- 全曲没有任何念白，每一句都唱出来。

## 六、段落标签与制作说明

- 全部结构标记（[主歌一] 等）只作段落指令，不得唱出。
- 不得增加未标注的衬词、喊声、说唱或即兴；拍手声是编曲层，不是歌词。
- 副歌一、2、Final 三遍逐字一致，不得有任何改动。
