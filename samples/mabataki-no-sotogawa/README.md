# 《まばたきの外側》文本样本

中文名《眨眼之外》。这是 `vocaloid-song-studio` 的完整参考链路，不是可替换名词后复用的歌曲模板。

## 学习顺序

1. `lyrics-design.md`：看故事、人物、双重意象、时间轴、Hook 和声音揭示如何先被设计。
2. `lyrics-ja.md`：看设计如何落成 11 段、64 行正式日语歌词。
3. `lyrics-reading-zh.md`：看原文、平假名唱读和中文意译如何逐行对应。
4. `music-agent-prompt.md`：看冻结歌词如何进入一份自包含制作委托。
5. `lyrics.lrc` 与 `lyrics.t.lrc`：看成品日文时间轴与中文翻译时间轴。
6. `cover-prompt.md`：看封面如何暗示双重含义但控制剧透。
7. `release-design.md` 与 `release-copy.md`：看社媒正文、标题、封面文案、AI 说明和剧透边界。

## 这个样本示范了什么

- 日语优先的高速电子摇滚 V 家叙事歌
- 第一人称不可靠叙事
- 魔法表层与病房现实的双重意象
- 普通副歌 Hook 复现与 Final Chorus 最小改字翻转
- 编曲从狭窄日常扩张到幻想高潮，再崩塌为干燥现实声
- 正式歌词作为真源，派生读音、翻译和制作提示词
- 生成以后以实际唱词制作 LRC
- 社媒发布时让音乐完成揭示，不用诊断名猎奇

## 不应复制什么

新作品不得复制或近似改写：

- 凪、アステリア等人物和名字
- 魔法少女误认病房的核心故事
- 契约腕轮、银色魔杖、白色宫殿等意象映射
- 「この世界が嘘なら」等 Hook 和歌词句式
- 四音魔法动机的叙事安排
- 母亲呼名和最后询问魔法的结尾
- 样本时间比例、旋律指令和封面构图

使用样本时，至少重新设计人物目标、情绪路径、核心 Hook、意象系统、声音动机、揭示机制和结尾动作。

## 未包含的素材

公开包不包含该歌曲的 WAV、MP3、视频、生成声线或封面图片。LRC 仅用于展示文本结构和同步文件关系。
