## 1. 设计检查

- [ ] 一句话命题具体到人物冲突
- [ ] 情绪路径每一步都发生变化
- [ ] 主人公和配角都有行动目的
- [ ] 揭示时间明确
- [ ] 表层歌曲在揭示前也成立
- [ ] 核心意象全部回收
- [ ] BPM、拍号、调性、音域和时长一致
- [ ] 段落时间相加接近目标时长
- [ ] 原创边界可脱离参考作品名表达
- [ ] 无占位、矛盾和无法验证的承诺

## 2. 歌词检查

### 故事

- [ ] 第一遍听能理解基本过程
- [ ] 每个 Verse 增加新动作或信息
- [ ] Bridge 完成不可逆变化
- [ ] Outro 留下后果，不重复总结
- [ ] 角色语言与身份一致

### Hook

- [ ] 核心 Hook 可在一次听后复述关键词
- [ ] 标题进入 Hook 或有充分理由不进入
- [ ] Chorus 2 重复策略明确
- [ ] Final Chorus 保留旋律识别度
- [ ] 没有在单段内机械过量重复

### 人味

- [ ] 动作和物件已表达情绪时没有追加解释
- [ ] 无中心思想式金句堆叠
- [ ] 无为了押韵产生的倒装或假诗意
- [ ] 抽象名词没有代替实际场景

## 3. 日语与唱读检查

- [ ] 语法、助词、搭配和语域自然
- [ ] 无中文逐字翻译腔
- [ ] 对应 Hook 行 mora 容量接近
- [ ] 高速段辅音密度可唱
- [ ] 句尾元音与延音合适
- [ ] 生僻汉字、数字、名字和缩写有固定唱读
- [ ] 读音文件逐行对应正式歌词
- [ ] 中文意译不提前剧透

## 4. 制作提示词检查

- [ ] 自包含，不依赖另一个文件
- [ ] 嵌入冻结歌词
- [ ] 允许操作与禁止操作分开
- [ ] 分段时间轴包含故事、旋律、配器、人声和声场
- [ ] 有自动生成与手动回退两条路径
- [ ] 有候选版本差异边界
- [ ] 有强制验收和针对性重试
- [ ] 不含艺人模仿、声纹克隆和现有歌曲复刻
- [ ] 不虚构平台按钮或已执行操作

## 5. LRC 与 Folia 检查

- [ ] 时间戳递增
- [ ] 最后时间早于音频总时长
- [ ] 无纯制作说明、空时间行和 End 标签
- [ ] 主 LRC 与实际唱词一致
- [ ] 翻译 LRC 时间戳与主 LRC 一致
- [ ] 音频与主 LRC 同基础名
- [ ] 封面使用 `cover.png` 等识别名
- [ ] 导入目录只暴露一个主音频
- [ ] 原始素材没有被意外删除或覆盖

## 6. 发布检查

- [ ] 标题有具体动作或问题
- [ ] 正文先讲人物，再讲 AI
- [ ] 预览没有泄露完整反转
- [ ] AI 参与说明真实
- [ ] 标签不使用敏感题材猎奇
- [ ] 封面无错误生成文字、品牌和水印

## 7. 失败回退

### 日语不自然

回到正式歌词重写，不通过提高语速或吞字硬塞。

### Hook 不抓耳

缩短核心句，统一 mora 或字数容量，增加结构复现；不要先增加高音和响度。

### 故事听不懂

补关键动作或物件，不增加旁白式主题解释。

### 揭示过早

删除确定性名词，保留可双重理解的声音和形状。

### 揭示不清

强化一个已埋过的对应物和声音空间，不临时增加全新设定。

### 编曲拥挤

减少持续琶音、中频吉他和合唱层，保留主唱与 Hook。

### 结果接近现有歌

废弃该版本，重写旋律动机、和声节奏、Bass 线、鼓组重音和前奏。

### 平台能力不足

输出手动制作包，明确无法控制的项目。不声称已经生成、试听或导出。

### LRC 与正式歌词冲突

判断音频是否重生。若不重生，以实际唱词制作 LRC；若要采用新歌词，先生成新音频。

## 8. 完成声明

可以分别声明：

- 设计文档已检查
- 歌词结构已检查
- 日文原文与唱读已对齐
- 提示词嵌入歌词已对齐
- LRC 结构已验证
- Folia 文件布局已验证

没有实际证据时不能声明：

- 旋律好听
- 发音正确
- BPM 和时长符合
- 混音通过
- Folia UI 已成功导入
- 社媒效果已验证

推荐结束语：

```text
文本制作包与确定性文件检查已经完成。尚未在外部音乐平台生成或试听，因此旋律、人声、混音和实际时长仍需用音频结果验证。
```
