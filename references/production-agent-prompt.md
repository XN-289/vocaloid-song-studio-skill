## 1. 提示词目标

最终提示词应让具备音乐制作能力的 Agent 在不反复询问普通细节的情况下，完成或尽可能推进：

- 日语歌词审校
- 原创作曲
- 和声与节奏
- 编曲和声音设计
- 虚拟人声方向
- 混音和母带
- 候选版本比较
- 生成后验收

平台不能直接生成音频时，Agent 应输出完整手动制作包，不得假装已经操作网站。

## 2. 自包含结构

按以下顺序组织：

```text
标题与角色
直接执行原则
最终任务参数
故事与人物
揭示时机
原创边界
分段时间轴
锁定歌词
固定唱读
旋律、Hook 与动机
人声表演
编曲与混音
自动执行路径
无生成能力时的回退包
短 Style Prompt
强制验收
不合格处理
最终回复格式
```

不要依赖“见另一个文件”。音乐 Agent 可能只接收到这一份提示词。

## 3. 歌词锁定协议

冻结歌词前不要声称锁定。冻结以后，提示词明确区分允许和禁止操作。

### 允许

- 一字多音或多字一音
- 词内音符分配
- 连音、延音、休止、换气
- 一行跨相邻小节
- 对白交给独立声线
- 假名或音素发音指导

### 禁止

- 增删换词
- 调换行序
- 合并或删除重复副歌
- 自动续写
- 增加未标注衬词、喊声、说唱或即兴
- 唱出段落标签和制作说明
- 因平台发音错误改写正式歌词

在歌词代码块前后加入稳定标记，便于脚本抽取：

```text
<!-- LYRICS_START -->
```text
[Intro]
...
```
<!-- LYRICS_END -->
```

## 4. 音乐参数

至少写清：

- 目标时长与允许范围
- BPM 与体感速度
- 拍号及局部变化
- 主调性或调性策略
- 建议音域
- 曲风高层描述
- 虚拟声线年龄感和音色
- 歌词语言
- Hook 重复方式

不要用具体艺人、现有歌曲或商业声库名字替代这些参数。

## 5. 分段生产指令

每一段写：

1. 时间范围
2. 叙事任务
3. 旋律特征
4. 配器进入或撤出
5. 声场与动态
6. 人声状态
7. 禁止提前出现的信息

示意：

```text
2:34–2:56 Bridge
叙事：幻想物件显出真实对应物
旋律：由连续句碎裂为短句
配器：强拍抽空，只留低频脉冲、轮子和荧光灯
声场：现实声更干、更近
人声：开始失稳但仍保持可懂
禁止：直接念诊断名
```

## 6. 人声与歌声合成

描述声音能力，不描述身份模仿：

- 音域
- 清亮或厚度
- 合成质感强度
- 辅音精度
- 真假声比例
- vibrato 数量和宽度
- 情绪路径
- 每段的声线变化
- 对白与主唱的距离关系

示例：

```text
年轻但不幼儿化的原创女性虚拟声线，清亮、纤细、略带数字边缘。高速日语辅音清楚，副歌明亮但不尖叫。Bridge 出现轻微颗粒和音高漂移，Outro 回到单层近距离干声。
```

不要写“像某某一样唱”，也不要要求复刻声纹。

## 7. 自动执行与回退

### 可以生成音频

1. 内部检查歌词结构与固定唱读。
2. 从零创作旋律、和弦、动机和编曲。
3. 生成 2 个候选版本，差异集中在人声情绪和声音设计强度。
4. 不把候选版做成两首完全不同的歌。
5. 按验收表检查并推荐一版。
6. 首轮失败时只修失败项一次。

### 不能生成音频

按固定顺序输出：

1. Lyrics
2. Short Style Prompt
3. Production Prompt
4. Voice Direction
5. Structure Map
6. Pronunciation Guide
7. Negative Instructions
8. Platform Steps
9. Limitation Note

平台按钮和参数不确定时使用条件表述，不虚构界面。

## 8. 验收与重试

### 歌词

- 段落、行数和文本逐字一致
- Hook 复现方式正确
- 固定唱读正确
- 无新增歌词和制作标签演唱

### 故事

- 关键过程第一次听可理解
- 揭示没有过早
- 双重意象得到回收
- 表层快乐或力量真实成立

### 音乐

- BPM、时长和音域在范围内
- 主唱清楚
- 各段动态和声场可辨
- Bridge 不是普通 EDM Drop
- Final Chorus 保持旋律识别度

### 原创

- 无可辨认现有旋律、riff、歌词或采样
- 无声音克隆和艺人模仿
- 有独立 Hook、动机与声音叙事

### 重试

- 发音错误：用假名、音素或局部人声重生
- 歌词塞不下：改音符分配和换气，不改词
- 编曲遮蔽：减持续琶音和中频吉他
- 揭示过早：降低现实声清晰度
- 揭示不清：加强物件和空间对比，不念诊断
- 过像现有作品：废弃版本，重写旋律和声节奏

## 9. 短 Style 字段

短字段优先保留：

1. 原创与语言
2. BPM 和曲风
3. 主唱能力
4. 核心配器
5. 结构性声音变化
6. 禁止模仿

通用骨架：

```text
Original Japanese vocal-synth narrative electro-rock, [BPM], [minor/major strategy], precise rapid Japanese diction, original synthetic female lead, [core instruments]. [Verse sound] expands into [chorus sound], then [bridge collapse] and [outro state]. Strong original chorus hook, no artist imitation, no voice cloning, no borrowed melody, no copyrighted samples.
```

短字段不能替代完整制作提示词；它只用于平台字符受限输入框。
